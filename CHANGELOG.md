# Changelog

История заметных изменений. Формат — упрощённый
[Keep a Changelog](https://keepachangelog.com/).

Записи группируются по версиям или датам релизов. Для проектов без
формального версионирования допустимо использовать дату как заголовок.

Категории:
- **Added** — новая функциональность.
- **Changed** — изменения в существующей функциональности.
- **Fixed** — исправления багов.
- **Removed** — удалённая функциональность.
- **Deprecated** — то, что помечено к удалению, но пока работает.
- **Security** — изменения, важные с точки зрения безопасности.

Если изменение связано с задачей из `BOARD.md` / `BACKLOG.md`,
запись **обязательно** содержит T-ID в скобках, например:
`Added: Превью постов в Telegram (T<NNN>).` Это сохраняет уникальность
T-ID между релизами — `CHANGELOG.md` единственное persistent-
хранилище номеров завершённых задач (см. правило нумерации
в `README.md`).

## [Unreleased]

- Fixed: объекты нового слоя ссылаются на явную запись «нет заливки»
  (раскладка снята с файла, сохранённого самим CorelDRAW 26) — без неё
  Corel замыкал открытую трассу хордой и заливал её из унаследованного
  стиля (T008).
- Changed: возвращён полный перенос исходных слоёв (T008 удалял кривые
  зоны — отменено): выход = оригинал целиком + новый слой с чистыми
  красной и синей линиями (T009).

- Fixed: тела чанков укладываются в data-файлы строго в порядке обхода
  дерева (CorelDRAW читает пулы потоком, а не по смещениям из стабов) —
  без этого файл с добавленным слоем не открывался; воспроизведено и
  проверено в настоящем CorelDRAW 26 (T007).

- Fixed: пересобранные loda-чанки пишутся в родной раскладке Corel
  (таблицы смещений и типов с сентинелом полной длины, тела аргументов
  подряд без выравнивания) — прежняя раскладка читалась libcdr, но не
  самим CorelDRAW (T006).

- Added: файл без залитой зоны распознаётся честно: одиночный режим —
  внятный отказ без трейсбека, пакетный — пропуск без ошибки (T005).

- Added: пакетный режим по умолчанию — запуск без аргументов
  обрабатывает все .cdr текущей папки, кроме готовых *-lines.cdr (T004).

- Changed: результат добавляется отдельным новым слоем «Двойная линия»,
  исходное содержимое (заливка, другие слои) не меняется; классификация
  ограничена слоем залитой зоны (T003).

- Added: GitHub Actions CI — гейты + сборка `lbs-liner.exe` (PyInstaller)
  со смоуком на синтетическом CDR; генератор синтетики вынесен в
  `lbs_liner.synthetic`, образец `examples/sample.cdr` (T002).
- Added: преобразование залитой области в двойную красно-синюю линию —
  чтение/запись CDR X7+ своими силами, снятие искусственных рёбер и
  заливки, офсеты через shapely, параметры `--width`/`--gap` (T001).
